# Views

Flutter UI views.

| File / directory | View |
|------------------|------|
| `login_view.dart` | Login (Ed25519 identity, passkey; password field is a deprecated-stub path) |
| `main_navigation.dart` | Shell navigation between the main views |
| `dashboard_view.dart` | Main dashboard: tunnel state, node info, quick actions |
| `peers_view.dart` | P2P mesh peer list with live stats |
| `network_monitor_view.dart` | Network activity monitor |
| `tree_browser_view.dart` | Permission tree browser |
| `node_detail_view.dart` | Single-node detail and edits |
| `servers_view.dart` | Known servers and latency |
| `certificates_view.dart` | Certificate status and issuance |
| `settings_view.dart` | App settings |
| `account_view.dart` | Account, devices, and group link tokens |
| `admin_console/` | Server administration group: dashboard, backends, logs, models, system info, plus the admin server provider |
